# 写作台（dsh-writer-studio）

DeepSeek Harness 的长篇小说写作插件：右侧栏可视化设定面板 + 对话内强制写作流程，解决长篇写作的遗忘前文、设定冲突、写飞字数与串线问题。

## 下载与安装

1. 下载仓库里的 `dsh-writer-studio-0.4.0.zip`。
2. 解压到任意目录。
3. 在解压目录运行：

```powershell
node install.mjs
```

4. **完全退出并重启 DeepSeek Harness**（不是刷新页面）。
5. 右侧栏引导页会出现「写作台」。

## 功能

- 书籍：书名、类型（可选可自填）、简介（可 AI 生成）、每章字数区间。
- 角色：姓名、性别、年龄、长相、性格、身份、故事定位；AI 生成/修改。
- 世界观：时代、规则、势力、禁忌；AI 生成/改写。
- 重要地点：城市/场所/秘境等，支持「包含」层级与「串联」关联；AI 生成/修改。
- 叙事分支：主线 / if线 / 前传 / 后传 / 外传 / 番外；每条分支必须单独填写时间线。
- 章节：按分支分组、分支内章序、本章时间线；AI 起草；已有章节可编辑分支/章序/时间线/标题/梗概。
- 对话：`writer_start` 开启写作模式，`writer_context` 注入上下包，`writer_save_chapter` 落盘时强制字数/梗概/重复度校验，`writer_recall` 检索前文。

## 数据位置

`~/.dsh/writer-studio/`（`state.json` + 每章 markdown）。

## 说明

AI 生成默认跟随当前对话的模型；可在插件配置 `config.ai` 里显式指定 provider/model。插件不提供绕过模型安全策略或法律限制的功能。
